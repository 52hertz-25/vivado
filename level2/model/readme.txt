LeNet-5 硬件仿真基准数据包 - 使用说明
 适用: HLS (Vivado/Vitis HLS) 仿真验证


【文件清单】
├─ hw_weights/       5层浮点权重 (txt, 行主序展平)
├─ hw_feature_maps/  7个中间层特征图 (npy, 逐层比对用)
├─ input_raw.txt     原始输入像素 (32x32, 0~255, 标签7)
├─ max_abs_stats.txt 每层权重最大绝对值 (量化缩放参考)
└─ model_shapes.txt  各层输入输出尺寸

网络结构（按前向顺序）：
------------------------------------------------------------
输入层     : 1x32x32（单通道灰度图）

1. Conv1   : 卷积核 5x5, 步长 1, 填充 0
             输入 1 通道 → 输出 6 通道 (28x28)
             激活: ReLU

2. Pool1   : 最大池化, 核大小 2x2, 步长 2
             6x28x28 → 6x14x14

3. Conv2   : 卷积核 5x5, 步长 1, 填充 0
             输入 6 通道 → 输出 16 通道 (10x10)
             激活: ReLU

4. Pool2   : 最大池化, 核大小 2x2, 步长 2
             16x10x10 → 16x5x5

5. Conv3   : 卷积核 5x5, 步长 1, 填充 0
             输入 16 通道 → 输出 120 通道 (1x1)
             激活: ReLU
             (相当于全连接层 400 → 120)

6. Flatten : 将 [120,1,1] 展平为 [120]

7. FC1     : 全连接层 120 → 84
             激活: ReLU

8. FC2     : 全连接层 84 → 10 (输出 logits)
             无激活函数 (Softmax 可省略, 不影响 argmax)
------------------------------------------------------------
注意事项：
- 所有层均无偏置 (bias=False)
- 全连接层在硬件中可复用卷积层的 MAC 单元
- 输入预处理必须为: (x/255 - 0.1307) / 0.3081

─────────────────────────────────────────────────────────────
【1. 权重文件 hw_weights/*.txt】
   - 每行一个浮点数, 行主序(Row-major)展平
   - 无偏置 (所有层 bias=False)
   - 各层详情:
     conv1: [6,1,5,5] -> 150个
     conv2: [16,6,5,5] -> 2400个
     conv3: [120,16,5,5] -> 48000个
     fc1:   [84,120] -> 10080个
     fc2:   [10,84] -> 840个
   - 总参数量: 61470

─────────────────────────────────────────────────────────────
【2. 特征图文件 hw_feature_maps/*.npy】
   - 用于逐层位比对定位Bug
   - 对应输入图片: 标签=7
   - 各层形状:
     conv1:  (1, 6, 28, 28)    pool1: (1, 6, 14, 14)
     conv2:  (1, 16, 10, 10)   pool2: (1, 16, 5, 5)
     conv3:  (1, 120, 1, 1)    fc1:   (1, 84)
     fc2:    (1, 10)
   - 比对方法示例 (Python):
       import numpy as np
       sw = np.load('conv1.npy')
       hw = 你的硬件输出
       diff = np.abs(sw - hw)
       print(diff.max(), diff.mean())

─────────────────────────────────────────────────────────────
【3. 原始输入 input_raw.txt】 
   - 1024个整数 (32x32), 值域 0~255
   - 硬件Testbench 喂入Conv1前 必须做预处理:
     Step1: x = pixel / 255.0          # 归一化到[0,1]
     Step2: x = (x - 0.1307) / 0.3081  # 标准化
   - 做完上述两步后, 输出才能与 conv1.npy 对齐

─────────────────────────────────────────────────────────────
【4. 量化参考 max_abs_stats.txt】
   - 每层权重的 max_abs, 用于计算缩放因子 scale
   - 公式: scale = target_max / max_abs
   - 例: 8位定点 -> scale = 127 / max_abs

─────────────────────────────────────────────────────────────
【5. 尺寸参考 model_shapes.txt】
   - 各层输入输出形状, 供C++数组定义参考

─────────────────────────────────────────────────────────────
【快速验证流程】
  1. 加载 input_raw.txt → 归一化/标准化 → 比对 conv1.npy
  2. 逐层前向 → 逐层比对特征图
  3. 参考 max_abs_stats.txt 做权重量化
