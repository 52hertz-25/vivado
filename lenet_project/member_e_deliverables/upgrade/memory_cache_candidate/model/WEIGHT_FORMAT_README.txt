============================================================
LeNet-5 权重文件格式说明
============================================================

【文件列表】
- conv1.weight.txt  (150个浮点数)
- conv2.weight.txt  (2400个浮点数)
- conv3.weight.txt  (48000个浮点数)
- fc1.weight.txt    (10080个浮点数)
- fc2.weight.txt    (840个浮点数)

【排列顺序】
- 卷积层 (conv1/conv2/conv3):
  按 [输出通道, 输入通道, 核高, 核宽] 顺序展平 (行主序)
  例: conv1 形状 [6,1,5,5] -> 前25个数 = 第0个输出通道的卷积核

- 全连接层 (fc1/fc2):
  按 [输出维度, 输入维度] 顺序展平 (行主序)
  例: fc1 形状 [84,120] -> 前120个数 = 第0个输出神经元的权重向量

【数据类型】
- 当前: FP32 (float), 精度 %.8f
- 量化为INT8时, 参考 max_abs_stats.txt 计算缩放因子:
  scale = 127 / max_abs
  量化后整数范围: [-127, 127]

【注意】
- 所有层均无偏置 (bias=False)
- 总参数量: 61470
